1) Diffference Between Where and Having ?

Where :
    Filter will be applied on Individual rows of table
    It will execute before grouping


Having :
    Filter will be applied on group records of table
    It will execute after grouping


2) Difference between group By and Order By ?

Group By :
    Groups the records for aggregation
    It required the aggregations functions
    number of rows in output is reduced 
    It will be using before aggregate functions, after WHERE

Order BY :
    Sorts the records
    It doesn't required the aggregations functions
    number of rows in output is same as number of rows in input
    It will be using end of the query
