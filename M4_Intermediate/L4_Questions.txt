1) Is that like we have use same column used in group by and used in aggregate functions ?
    Not exactly

    *) Correct Query 
    
    SELECT region, SUM(amount)
    FROM sales
    GROUP BY region;

    *) Wrong Query

    SELECT region, product, SUM(amount)
    FROM sales
    GROUP BY region;

    *) Correct Query 

    SELECT region, product, SUM(amount)
    FROM sales
    GROUP BY region, product;


2) Diffference Between Where and Having ?

Where :
    Filter will be applied on Individual rows of table
    It will execute before grouping


Having :
    Filter will be applied on group records of table
    It will execute after grouping


3) Difference between Order By and Group By ?

Group By :
    Groups the records for aggregation
    It required the aggregations functions
    number of rows in output is reduced 
    It will be execute after WHERE and before aggregate functions
    It will treat the all NULL values are equal

Order BY :
    Sorts the records
    It doesn't required the aggregations functions
    number of rows in output is same as number of rows in input
    It will be execute end of the query
    It will treated NULLs as unknown / missing values
