1) What is Aggregation Functions ?
	It perform a calculation on multiple rows and return a single result.


2) what is GroupBy Clause ?
	It is used to group related data
	applies the aggregate function (avg,count,max,min.sum) on each group to produce the summarize result


3) What is Having clause ? 
    Filter will be applied on Individual group of table 


4) Difference between Group By and Order By ?

Group By :
    Groups the related data and applies the aggregate function on each group to produce the summarize result
    It require aggregation function and functions are Avg, Count, Max, Min and Sum
    It will treat the all NULL values are equal
    It will be execute after WHERE and before aggregate functions
    number of rows in output is reduced 

Order BY :
    Sorts the records in ascending order (ASC) by default
    It doesn't required the aggregations functions
    It will treated NULLs as unknown / missing values
    It will be execute end of the query
    number of rows in output is same as number of rows in input


5) Diffference Between Where and Having ?


Having :
    Filter will be applied on Individual group of table and filter aggregated results
    It require aggregate functions
    It will treat the null values as equal in group by and null values ingonerd by aggregate 
    It will execute after grouping
    It slow in the performance

Where :
    Filter will be applied on Individual rows of table and filter raw data
    It doesn't require aggregate functions
    It will treat null values as UNKNOWN with help of IS NULL operator
    It will execute before grouping
    It improves the performance because of reduces data before grouping (predicate pushdown)
