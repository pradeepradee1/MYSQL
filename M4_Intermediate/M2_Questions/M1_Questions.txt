1) Can we use GROUP BY without aggregate functions?    
    Yes, but it works like DISTINCT.

        SELECT dept
        FROM emp
        GROUP BY dept;

    *)  Proper Query
    
        SELECT dept, COUNT(*) AS total_employees
        FROM emp
        GROUP BY dept;

    

2) Do we need to use same column used in group by and used in aggregate functions ?
    Not exactly

    *) Correct Query 
    
    SELECT region, SUM(amount)
    FROM sales
    GROUP BY region;

    *) Wrong Query
    
    SELECT region, product, SUM(amount)
    FROM sales
    GROUP BY region;

    *) Correct Query 

    SELECT region, product, SUM(amount)
    FROM sales
    GROUP BY region, product;


3) Can we use columns in SELECT that are not in GROUP BY?
    No

    *) Wrong Query 

    SELECT department, salary
    FROM employees
    GROUP BY department;

    *) Correct Query 

    SELECT department, AVG(salary)
    FROM employees
    GROUP BY department;





4) Diffference Between Where and Having ?

Where :
    Filter will be applied on Individual rows of table
    It will execute before grouping
Having :
    Filter will be applied on group records of table
    It will execute after grouping



5) Difference between Order By and Group By ?

Group By :
    Groups the records for aggregation
    It required the aggregations functions
    It will treat the all NULL values are equal
    It will be execute after WHERE and before aggregate functions
    number of rows in output is reduced 

Order BY :
    Sorts the records
    It doesn't required the aggregations functions
    It will treated NULLs as unknown / missing values
    It will be execute end of the query
    number of rows in output is same as number of rows in input


6) How the groupBy handle NULL values ?

It will treat the all NULL values are equal
