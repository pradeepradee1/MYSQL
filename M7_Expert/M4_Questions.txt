1) DB GroupBy and Windows functions ?

GroupBy :
Groups the records for aggregation
aggregation function are Avg, Count, Max, Min and Sum
It will treat the all NULL values are equal
It will be execute after WHERE and before aggregate functions
Number of rows in output is reduced 


Windows :
It does not Groups the records and It creates a logical partition and But keeps all rows
Windows functions are row_number, Rank, Dense_rank, lead , lag  etc
It will treat the all NULL values are equal
Window functions are executed after having clause
Number of records in output is same as input
