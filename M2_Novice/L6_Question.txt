Diffrence Between Unique (constraint) and distinct keyword ?
    Unique :
        Unique is keyword and constraint 
        Prevent the duplicate values from columns of table during the table creating 
        It will be using in DDL statment 
        If Column has multiple null's values It will  treat as unequal ( for ex : both null are not same )
        It focus in column in the table
        
    
    Distinct :
        It is keyword
        Remove duplicate values from rows of table during the query result
        It will be using select statemnt 
        If Column has multiple null's values  It will treat as equal ( for ex: both null are same )
        It focus in rows in query result
