1) Difference between Primary Key and Foreign Key ?

Primary Key :
				Objective :
				Primary key is used to identify the unique record of a table

                The Combination of not null and unique constraints						
				It will not allow the Null and duplicate values 
				
                A table which contains primary key is considered as parent/Master/Base table.

Foreign Key :
				Objective :
                implement relationship between the two tables by using primary key of one table
				nd we can have foriegn key in other table.

				Foriegn key contains duplicates and null values also.

				A table which contains foriegn key is known as child/Detailed/Derived table.



2) Diffrence Between Unique (constraint) and distinct keyword ?
    Unique :
        Unique is keyword and constraint 
        Prevent the duplicate values from columns of table during the table creating 
        It focus in column of the table (link with 2nd steps)
        It will be using in DDL statment (link with 2nd steps) 
        If Column has multiple null's values It will  treat as unequal ( for ex : both null are not same )
        
        
    
    Distinct :
        It is keyword
        Remove duplicate values from rows of table during the query result
        It focus in rows of table (link with 2nd steps)
        It will be using select statemnt (link with 2nd steps)
        If Column has multiple null's values  It will treat as equal ( for ex: both null are same )
