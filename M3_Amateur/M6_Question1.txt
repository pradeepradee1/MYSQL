1) Difference between Drop and Truncate ?

Drop 		:
			It is DML Operation
			It removes a database object (like a table, view, or index) 
			Deletes the data and table structure permanently
			Cannot be rolled back in most databases


Truncate	:
			It is DDL Operation
			Deletes the data and keeps the table structure
			Cannot be rolled back in most databases


2) Difference between Truncate and delete ?

Truncate 	:
			It is DDL Statement
			Deletes the data and keeps the table structure
			Cannot be rolled back in most databases

Delete		:
			It is DML Statement
			Deletes specific rows from a table based on a WHERE clause
			Can be rolled back



3) Difference between the DDL and DML ?
		
		DDL 													DML

1) Used to create the table or define the database schema		1) used to manipulative the records, we can insert, update, delete the data

2) CREATE, ALTER, DROP, TRUNCATE, RENAME						2) INSERT, UPDATE, DELETE

3) Queries can’t be a rollback									3) Queries can be a rollback
