
1) Can we insert/update/delete into a view ?
        Yes, if the view is updatable.


2) When is a View Updatable ? 
        *) It is based on one single table.
        *) It does NOT use DISTINCT, GROUP BY, Aggregate functions, Complex joins, UNION
and Subqueries


3) What are limitations of views? 
        
        *) Cannot Store Data Permanently
        *) No Indexes
        *) All Views Are Not Updatable (View Updatable)
        *) Performance Issues
        *) Security Is Limited 
                Users may still access base tables if granted permission.


4) What is indexed view?
        It has a clustered index
        It store Physically data on disk 
        Once indexed then the view behaves like a materialized view
        It improves performance for complex aggregations and reporting queries.
