1) Can we insert/update/delete using CTE ?

        Yes , You can use a CTE with UPDATE and DELETE in most modern databases.

        WITH dept_avg AS (
                                SELECT department_id, AVG(salary) AS avg_salary
                                FROM employees
                                GROUP BY department_id
                        )
        UPDATE employees JOIN dept_avg ON employees.department_id = dept_avg.department_id
        SET employees.salary = dept_avg.avg_salary
        WHERE employees.salary < dept_avg.avg_salary;


2) What are advantages of CTE?

        *) Improves Readability
        *) Modularity of complex sql Queries ( Better Logical Separation )
        *) Supports Recursive Queries
        *) Reusability Within Same Query
        *) Helps in Complex Transformations
        *) Works with SELECT,INSERT, UPDATE, DELETE
        

3) What is a Temporary Table? (temp table)
        
        It is used to create the table for temporarily
        Storing the data in physical
        Can be indexed
        Scope is Session or transaction
        

#Note : Focus on Temporay table 

4) Difference between CTE and Temporary Table ?

Temporary Table :

        *) It is used to create the table for temporarily
        *) It store the data in physical
        *) Index can be created
        *) Scope is Session or transaction
        *) It doesn't suit for recursion
        *) It is good in performance for large data


CTE : 
        *) It is Used to define a temporary result set
        *) It doesn't store the data in physically
        *) Index can't created
        *) Scope is single query
        *) It suit for recursion
        *) It is average in performance for large data



5) Which performs better CTE or subquery ?

        *) CTE and subquery have similar performance because the optimizer 
produces the same execution plan. 
        *) Performance depends more on indexing, query structure, and execution plan.



6) What is recursive CTE?

        *) The Query References by itself until a condition is matching
        *) Consists of an anchor query and a recursive query combined using UNION ALL. 
        *) It is commonly used to process hierarchical (or) tree structured data
