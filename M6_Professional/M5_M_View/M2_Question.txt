1) What are types of refresh in materialized view?
    There are mainly three types of refresh:

    1.1) Complete Refresh
    1.2) Fast Refresh
    1.3) Force Refresh

    1.1) Complete Refresh (Full Refresh) :
        Refresh everything from scratch
        Re-executes the entire query from scratch
    
    1.2) Fast Refresh (Incremental Refresh) :
        Refreshes only the changed data
        executes only affected query

    1.3) Force Refresh :
        Attempts Fast Refresh
        If not possible → falls back to Complete Refresh


2) On Demand vs On Commit (Refresh Timing)

    On Demand :
                Refresh by manually or scheduled

    On Commit :        
                Refresh by automatically when base table commits
