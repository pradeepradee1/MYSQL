1) Difference between the SubQuery and Correlation subquery ?

SubQuery :
    A query inside another query 
    It runs independently of the outer query	
    Runs once and gives a result to the outer query	
(talks about storage)
    Does not keep reference columns from the outer query	
    It is faster, because it's executed once	

Correlated Subquery
    A query inside another query 
    It depends on values from the outer query
    Runs once for every row in the outer query
(talks about storage)
    keep References columns from the outer query
    It is slower, since it's executed multiple times


2) Diffrence between CTE and View ?
    CTE :
    define a temporary result set that can be referenced in the main query
(talks about storage)
    Not persistence ( temporary result will not be there after execution is completed)
    Not resuable
    It doesn't store any data 

    View :
    It is Virtal table 
(talks about storage)
    persistence ( we can virual table multiple purpose )
    resuable
    It Store the metadata of data

3) Difference between View and Mview ?
    View :
        Virtual Table 
        Does not store data
        Always fetches the data from live table
(talks about storage)
        It doesn't consume storage 
        It is Slower 
    
    MView :
        Physical table
        Stores data physically	as like table 
        Needs manual intervention to refresh the data  from table
(talks about storage)
        Consumes storage	
        Faster 

4) Difference between In and EXISTS ?
    IN :
        It Will check the value exist
        It suit for work with Small set  ( list )
        Performance will be Slower with large result sets	

    Exist :
        It Will check If rows exist
        It suit for work with Large sets ( correlated queries )
        Performance will be Faster with large result sets
