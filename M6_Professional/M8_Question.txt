1) Differences Between Subquery and JOIN
    Subquery :
        A query inside another query.
        Filter rows based on some condition from another table.
        It is used for Filtering, aggregation
        when you work with Large data It is Risky if correlated 
        Performance Can be slow (correlated)

    Join :
        combines two or more tables.
        Show data from multiple related tables
        It is used for Retrieving related data
        when you work with Large data It is Better optimized   
        Performance Usually faster


2) What is the difference between IN, EXISTS, and = ANY in subqueries?

    IN :
        It Will check the value exist
        It suit for work with Small set  ( list )
        Performance will be Slower if subquery returns a large number of rows	
        It behave unexpectedly if subquery contains NULL values.

    Exist :
        It Will check If rows exist
        It suit for work with Large sets ( correlated queries )
        Performance will be Faster if subquery returns a large number of rows 
        It is Safer when NULL values exist.

    ANY :
        It similar to the IN operator
        It Will check the value exist
        It suit for work with Small set  ( list )
        Performance will be Slower with large result sets
        It behave unexpectedly if subquery contains NULL values.



3) Diffrence between CTE and View ?
    CTE :
    define a temporary result set that can be referenced in the main query
(talks about storage)
    Not persistence ( temporary result will not be there after execution is completed)
    Not resuable
    It doesn't store any data 

    View :
    It is Virtal table 
(talks about storage)
    persistence ( we can virual table multiple purpose )
    resuable
    It Store the metadata of data


4) Difference between CTE vs Subquery ?

CTE :
    It is Used to define a temporary result set using with clause
    Can be referenced multiple times in same query
    Improves readability
    It support Recursive 
    

Subquery :
    A query inside another query
    Can't be referenced multiple times
    Not Improves readability
    It doesn't support Recursive
    

5) Difference between View and Mview ?
    View :
        Virtual Table 
        Does not store data
        Always fetches the data from live table
(talks about storage)
        It doesn't consume storage 
        It is Slower 
        It is used for Abstraction, security
    
    MView :
        Physical table
        Stores data physically	as like table 
        Needs manual intervention to refresh the data  from table
(talks about storage)
        Consumes storage	
        Faster 
        It is used for Performance optimization
