
1) Difference between Set and Join 

			Set                                             Join

It combines data into new rows or records           It combines data into new columns
Set Operators are 									Join are
	Union, Union all , Intersection						Inner Join , Left outer join ,right outer joins , full outer joins


For Ex:                                             For Ex:
		select dno from emp 								(inner join on a.dno = b.dno) 
		union 
		select dno from dept
